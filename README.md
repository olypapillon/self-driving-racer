# Self-Driving Racer

A pseudo-3D arcade racer written in Python with pygame-ce, where six
self-driving algorithms race one lap against each other, and you can race
them too. The algorithms range from hand-written rules to an evolved neural
network.

## ▶ [Watch them race in your browser](https://olypapillon.github.io/self-driving-racer/)

**https://olypapillon.github.io/self-driving-racer/**

Click the page once to start. The first load takes a few seconds while Python
loads in the browser.

The screen has three parts: **who drives** and the race controls on the left,
the race in the middle, and the **leaderboard** on the right. Click the
buttons, or use the keys:

1. **Pick who drives** (keys `1`–`7`). The camera follows that car and a new
   race starts:

   | Key | Driver |
   |---|---|
   | `1` | Baseline |
   | `2` | Pure Pursuit |
   | `3` | Stanley |
   | `4` | MPC Planner (the default) |
   | `5` | Imitation NN |
   | `6` | Evolved NN |
   | `7` | **You**: drive with the arrows or WASD |

2. **Pick the race** (`M`):
   - **Battle:** everyone on one grid, with slow traffic to get past. Pick
     *You* and all six algorithms race you.
   - **Time trial:** alone on the track, chasing the blue ghost of the fastest
     run so far. The HUD shows the gap to the ghost.
3. **Pick the speed** (`F`): 1×, 2×, 4× or 8× fast-forward while an algorithm
   drives. It only changes how quickly the race is shown, not the race itself.

Your best time-trial lap and best battle place go on the leaderboard next to
the algorithms, saved in your browser. `Tab` takes over the car mid-race (or
hands it back), but those runs don't count. `R` restarts.

When your car finishes, a results table shows the finishing order and fills in
as the others cross the line.

Generated by `src/benchmark.py` into [`leaderboard.json`](leaderboard.json).

**Why the Evolved NN wins:** it takes both long bends flat out at full steering
lock, while the hand-written drivers slow to about 0.88× top speed. It also hits
the boost pad just before the first bend and carries the extra speed through
it. The physics allow both; the other drivers are just more cautious.

## Controls

| Key | Action |
|---|---|
| `1`–`7` | Pick who drives: an algorithm, or you (`7`) |
| Arrows / WASD | Drive, when you are driving |
| `M` | Switch between battle and time trial |
| `F` | Fast-forward (1×, 2×, 4×, 8×) |
| `Tab` | Take over the car mid-race, or hand it back |
| `R` | Restart the race |

Everything is clickable in the side panel as well. The see-through blue car is
the ghost of the fastest run so far.

## The track

One lap of about 25 seconds: two hilly straights and two 180° bends. Boost
pads (orange) push a car past its normal top speed for a moment. Mud (brown)
slows a car and takes away its grip.

## The algorithms

All six drive through the same interface: each step they return
`(steering, throttle, brake)` and the shared physics move the car. They are in
[`src/drivers.py`](src/drivers.py), except the Baseline, which lives in the game.

- **Baseline:** steers toward a lane with a PD controller and follows a
  precomputed speed plan. It ignores boost pads and mud on purpose.
- **Pure Pursuit:** steers toward a point a set distance ahead on its chosen line.
- **Stanley:** corrects both heading error and sideways offset from the line.
- **MPC Planner:** simulates many candidate steering plans a short way ahead
  with the game's own physics and picks the cheapest. It is the slowest to run.
- **Imitation NN:** a small network trained to copy the MPC Planner
  (behaviour cloning plus DAgger).
- **Evolved NN:** starts from the imitation network and improves it with an
  evolution strategy that rewards lap time.

## Run it locally

Needs [uv](https://docs.astral.sh/uv/).

```bash
uv run python src/3D-game.py          # play
uv run python src/benchmark.py        # rebuild the leaderboard and ghosts
uv run python src/train_drivers.py    # retrain the neural networks (needs numpy, a dev dependency)
```

Browser build (the GitHub Action runs the same script on every push to `main`):

```bash
uv run --no-project --with pygbag==0.9.3 bash web/build.sh --serve
```

## Project layout

```
src/3D-game.py        game: track, physics, rendering, races
src/drivers.py        the self-driving algorithms
src/train_drivers.py  trains the Imitation and Evolved networks
src/weights/          trained network weights
src/benchmark.py      runs the races and writes leaderboard.json and ghosts/
web/                  browser build (pygbag)
LEARNING.md           the step-by-step learning path this project followed
```
